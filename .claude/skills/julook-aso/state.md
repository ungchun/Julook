### 핵심 원칙
- **App Store 검색 ≠ 네이버 검색** — DB에 있어도 App Store에서 안 찾는 키워드(무감미료막걸리/브랜드명/맛 프로필 등 Apps 0)는 전량 폐기.
- **고볼륨 = 경쟁앱 이름** — 데일리샷(Pop58)/키햐(Pop31)/술담화/요즘이술/비비노 → 키워드 필드 집중.
- **Apple 자동조합** — 제목·부제·키워드 단어가 막걸리추천/막걸리종류/술추천앱/막걸리앱 등을 자동 매칭. 통짜 토큰 안 넣고 슬롯 절약.

## 적용 가이드 (App Store Connect)

```
1. App Store Connect → My Apps → 주룩 → iOS App
2. 편집 가능한 버전(또는 "이 버전 준비 중") 클릭
3. App Name / Subtitle / Keywords 칸 비우고 위 3개 값 복붙
4. Save → Submit for Review (메타데이터만 변경이라 빌드 재업로드 불필요)
```
