### 변경 사유

이전까지 키워드를 추측·풀파일 기반으로 쌓았으나, 이번엔 **두 가지 실데이터로 처음부터 재설계**:

1. **주룩 DB 실측 (Supabase)** — 앱은 **막걸리 437종 / 양조장 208곳 전문 앱**. 위스키·와인·소주·사케 테이블 자체가 없음. → 주종 일반어(위스키/와인/하이볼/사케/소주/맥주/칵테일/증류주) **콘텐츠 근거 0이라 전량 제거**.
   - 무감미료 274종(63%), 수상작 134종, 맛 프로필 4축(단맛/신맛/걸쭉함/탄산), 평균 8.4도.

2. **AppFollow Keyword ranking 실측 (2026-06-12, Korea/iPhone)** — 78개 시드 키워드 추적 후 Rank·Apps(경쟁앱 수) 분석.

### 핵심 발견: **App Store 검색 ≠ 네이버 검색**

DB 근거가 있어도 App Store에서 아무도 안 찾는 키워드 다수 확인 (Apps 0 / Rank —):
- 무감미료막걸리·아스파탐·무첨가막걸리·달지않은막걸리·천연발효
- 맛 프로필(단/탄산/톡쏘는/산미/걸쭉한 막걸리)
- 수상막걸리·대상막걸리·주류대상·우리술대축제
- 생/수제/프리미엄/전통 막걸리·막걸리종류·순위·도감·일기·동동주
- **브랜드명 전량**(지평/복순도가/느린마을/송명섭/해창/나루생/호랑이배꼽/장수/국순당) — 사람들은 네이버·쿠팡에서 검색하지 App Store에서 안 함

### Surface 역할 분담

- **제목**: 막걸리·전통주 + 핵심 모디파이어(추천/기록/도감) — 우리가 #1~4 먹은 안방.
- **부제**: 기능·상황어(양조장/시음노트/탁주/약주/안주/홈술/혼술) — 전부 #3~12위.
- **키워드 100자**: 경쟁앱 이름(키햐/데일리샷/술담화/요즘이술/비비노/vivino/달리) + 롱테일 채움.
- **Apple 자동조합 활용**: `막걸리`(제목)+`종류/순위/선물`(키워드) → 막걸리종류/순위/선물. `술`(키워드)+`추천`(제목)+`앱`(키워드) → 술추천앱. 통짜 토큰 안 넣고 슬롯 절약.
