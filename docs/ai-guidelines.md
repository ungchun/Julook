# AI 작업 가이드라인

## 응답 언어
- 모든 응답은 **한글**로 작성
- 코드 설명, 변경사항 요약, 질문 등 모든 텍스트는 한글
- 코드 내 주석도 한글
- 코드 자체(변수명, 함수명)는 영어

## 빌드 규칙
- 코드 수정 후 **빌드 실행 금지**
- xcodebuild 또는 관련 빌드 도구 사용 금지
- 사용자가 명시적으로 요청할 때만 빌드 수행

## 작업 순서
1. 요구사항 분석
2. 필요한 파일 읽기 및 분석
3. 코드 작성 및 수정
4. 변경사항 요약 및 설명

## 보안
- API 키 하드코딩 금지
- 민감한 정보는 Keychain 사용
- 사용자 ID는 UUID로 관리 (Keychain 저장)

## 성능
- 이미지 비동기 로드
- 대용량 리스트는 LazyVStack/LazyHStack 사용
- 불필요한 상태 업데이트 방지

## 접근성
- VoiceOver 지원 고려
- 색상 대비 확인
- 동적 타입 지원
