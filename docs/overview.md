# 프로젝트 개요

## 목표
Julook은 막걸리 애호가를 위한 iOS 앱으로, 막걸리 정보를 제공하고 사용자 취향에 맞는 막걸리를 찾을 수 있도록 돕습니다.

## 주요 기능
- **검색 및 필터링**: 이름, 양조장으로 검색하고 특징별 필터링
- **특징별 찾기**: 단맛, 신맛, 걸쭉함, 탄산, 무아스파탐 등
- **신상 막걸리**: 최근 등록된 막걸리 5개 표시
- **랜덤 추천**: 앱 실행 시 랜덤으로 5개 추천
- **오늘의 랭킹**: 좋아요 수 기준 상위 3개 표시
- **주제로 찾기**: 수상 내역별 탐색
- **코멘트**: 리뷰 작성 및 공개/비공개 설정
- **리액션**: 좋았어요/아쉬워요 반응
- **내 막걸리**: 찜한 막걸리 관리

## 기술 스택

### 핵심 기술
- **언어**: Swift 6.0
- **UI**: SwiftUI
- **아키텍처**: TCA (The Composable Architecture) 1.11.0+
- **프로젝트 관리**: Tuist
- **로컬 데이터**: SwiftData (iCloud 동기화)

### 외부 라이브러리
- **Supabase 2.25.0+**: 백엔드 (DB, 스토리지)
- **TCACoordinators 0.10.1+**: 네비게이션 관리
- **SwiftNavigation 2.6.0+**: 네비게이션 유틸리티
- **Firebase**: Analytics, Crashlytics
- **Amplitude 1.13.9+**: 사용자 행동 분석

### 개발 환경
- iOS 17.0+ / Xcode 15.0+ / Swift 6.0+
